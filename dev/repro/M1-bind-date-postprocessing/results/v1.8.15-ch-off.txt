$ psql> EXPLAIN SELECT SUM(amount_dim) s FROM (SELECT id, amount_dim, created_at FROM orders) q WHERE created_at >= timestamp '2025-05-10 00:00:00'
plan_type | plan
logical_plan | CubeScanWrappedSql
physical_plan | CubeScanExecutionPlan, SQL:
SELECT `q`.`sum_q_amount_dim` `s` 
FROM (
  SELECT
        SUM(`orders`.amount) `sum_q_amount_dim`
      FROM
        repro.orders AS `orders`  WHERE (`orders`.created_at >= parseDateTimeBestEffort(?))
) AS `q`
LIMIT 50000
